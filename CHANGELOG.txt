LARPERS COIN SMP 26.3
CHANGELOG — 0.8.0
Date: 2026-11-12

Added
- Secure player trades with invitation, item offers, LPC offers, two-player confirmation, cancellation and inventory/balance validation.
- Daily and weekly quest objectives: block breaking, mature crop harvesting, mob kills and fishing.
- LPC shop purchases with configurable prices stored in plugins/LarpersCoin/features.yml, plus a clickable shop GUI.
- Clan and quest inventory menus.
- Persistent transaction history for player payments, daily rewards, bounty, lottery, shop, auction, clan bank, quiz and trades.
- Multiple-choice Minecraft quiz GUI with configurable question bank and score leaderboard.
- Shop categories, page navigation and 1/16/64 quantity controls.
- Clan leadership transfer (including offline members), confirmed clan dissolution, offline invitations and chest change audit.
- Two-page staff administration GUI with integrated shortcuts.
- Configuration guide for shop prices, quiz questions and permissions.
- Secure trade invitations expire after 60 seconds; either participant can cancel.
- Clan XP and level progression earned through quest activities.
- Clan leader/officer/member roles and officer bank withdrawals.
- Bilateral clan alliances using request and acceptance.
- Periodic feature-data saves and explicit flush on plugin shutdown.
- Atomic, disk-flushed replacement for both YAML data files to prevent partially written files.

Improved
- BUILD-PLUGIN.bat checks that JDK 25 is installed and writes Gradle stack traces to BUILD-PLUGIN.log.
- README and docs/STATUS.md now describe the implemented commands and remaining limitations.
- Plugin version bumped to 0.8.0.

- Expanded admin GUI actions and paginated player-management pages.
